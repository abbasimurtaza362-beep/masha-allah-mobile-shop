# Localhost Screenshot Guide

After importing the database and starting Apache/MySQL in XAMPP, capture the following screenshots in your browser. Save them in a folder named `submission-screenshots` and use clear names such as `01-home-desktop.png`.

| File name | Required evidence |
| --- | --- |
| `01-home-desktop.png` | Home page at desktop width, showing navigation, hero, services, and featured products |
| `02-home-mobile.png` | Home page at approximately 390 px width to demonstrate responsiveness |
| `03-products-filter.png` | Products page after using category filter, search, or price sort |
| `04-contact-form.png` | Contact page with map and inquiry form |
| `05-admin-dashboard.png` | Logged-in admin dashboard with counts and recent inquiry area |
| `06-product-crud.png` | Product management form and product table |
| `07-image-upload.png` | Product form showing selected image upload and resulting product image |
| `08-services-crud.png` | Service management page |
| `09-inquiries.png` | Inquiry management page with test message |

Use your own test data for screenshots. Do not include real customer information, passwords, or database credentials in screenshots or the demo video.
