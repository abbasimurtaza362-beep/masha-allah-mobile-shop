# Assessment Submission Checklist

| Deliverable | Status before submission |
| --- | --- |
| PHP source package | Copy the final `php-xampp` folder and remove the temporary setup/seed scripts after initialization |
| GitHub repository | Create a repository, add a concise README, and push the source without database credentials or uploads containing private data |
| MySQL database | Include `schema.sql` and `seed.php`; export a final `.sql` backup from phpMyAdmin if your instructor requires current test data |
| Localhost screenshots | Capture the evidence listed in `screenshots.md` |
| Demonstration video | Follow `demo.md` and keep the recording within three to five minutes |
| Project report | Fill in the student name and date in `report.md`, then submit it in the format required by the instructor |

> Before sharing the project, delete `setup.php` and `seed.php` from the public localhost folder after use. Also remove any real contact messages and uploaded files that should not be shared.
